Koneksi LIVE ke Exness dilakukan lewat MetaApi (jembatan cloud resmi ke akun MT5 — Exness tidak punya API web publik). Buat token gratis di app.metaapi.cloud. Nama server terlihat di email pembukaan akun / aplikasi Exness. Token boleh dikosongkan bila server sudah dikonfigurasi lewat file .env.

Mode demo memakai simulator harga XAU/USD dan saldo virtual $10.000 — cocok untuk menguji bot tanpa risiko.

🤖 GoldScalper — Pengaturan

Saat di-start, bot langsung mengeksekusi order secara otomatis tanpa konfirmasi, termasuk break-even & trailing stop. Posisi tak terbatas + risk tinggi bisa menguras margin dengan cepat — penjaga "min. free margin" mencegah margin call, bukan menjamin profit.
